# Alternator Trainer

A single-page training site for marine (boat) alternator charging systems.

- **Learn**: clickable diagram of every part (rotor, stator, rectifier, regulator, brushes, B+ cable, grounds, exciter circuit, battery, battery switch) with what it does, how it fails and how to test it.
- **Quiz**: 10 random questions from a bank of 20, with explanations.
- **Diagnose**: a simulated engine with a multimeter (DC V, AC V ripple), clamp ammeter, carbon-pile load tester and visual inspection. Each job has one of 10 faults or no fault. Submit a diagnosis and see the key readings.

Open `index.html` in a browser. No build step.
